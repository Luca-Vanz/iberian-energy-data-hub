Installed generation capacity by technology

Installed net capacity describes the generating fleet available on 1 January of each year. It is measured in MW and is different from the electricity actually produced.

Loading official ENTSO-E capacity data…
Method. Annual installed net capacity is displayed by production technology as published by ENTSO-E (A68). Capacity has only a yearly frequency because the official series is annual. Values are not interpolated between years; missing observations remain missing. The current Hub archive starts in 2018, although earlier official ENTSO-E observations exist and can be added in a future archive extension.

Electricity generation by technology

Monthly generation shows which technologies produced electricity. Native average-MW observations are converted into energy using their actual interval duration and summed to GWh.

Loading official ENTSO-E generation data…
Method. ENTSO-E generation by production type (A75) is duration-weighted from its native hourly or 15-minute resolution and stored here as monthly energy. Monthly values can be summed into yearly totals; finer frequencies cannot be reconstructed from this monthly public table. Storage consumption is excluded. Missing source intervals are never filled with zero, and incomplete technology-periods are reported above the graph. The current Hub archive starts in 2018, although earlier official ENTSO-E observations exist.
