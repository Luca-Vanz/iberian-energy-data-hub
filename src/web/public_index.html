Iberian Energy Data Hub

Historical electricity-market data and analytics for Spain and Portugal

This public portfolio version provides historical OMIE day-ahead electricity-market analysis for Spain and Portugal. The project uses Python, SQL, SQLite, FastAPI and JavaScript to collect, validate, analyse and visualize Iberian energy-market data.
